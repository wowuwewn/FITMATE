# 실행과 확인

프로젝트 폴더 `D:\dev\Fitmate`에서 실행합니다. Node.js/npm과 브라우저 테스트용 Google Chrome이 필요합니다.

```sh
npm ci
npm run dev -- --host 127.0.0.1
```

기본 주소는 `http://127.0.0.1:5173`입니다. 현재 분석은 로컬 JSON으로 실행되며 AI 서버나 API 키 설정이 필요하지 않습니다. 이전 AI 연결 안내는 현재 실행 절차에 포함되지 않습니다.

## 주요 흐름 확인

1. 홈의 인트로와 커버를 확인한 뒤 제품 검색 또는 탐색으로 이동합니다.
2. 프로틴 B(P02)를 담고, 별도 `복용약 확인`에서 레보티록신 경구제(M02)를 추가합니다.
3. 조합함에서 88점과 주의사항 1건을 확인합니다.
4. `상세 정보 확인` → `마이너스 조합` → `근거와 출처`에서 R06을 확인합니다. `분석 기준`에서 규칙 기반 설명과 정보 부족, 점수 계산 근거를 확인합니다.
5. `최적화 분석`에서 프로틴 A(P01)를 선택하면 변경 후 점수 100점이 표시됩니다. 복용약은 그대로 유지됩니다.
6. 변경 후 조합을 확정·저장하고, `내 정보`에서 불러온 뒤 새로고침해도 제품 구성이 유지되는지 확인합니다.

조합 점수는 의학적 안전 점수가 아닙니다. 실제 함량·복용 시간·개인 상태가 반영되지 않는 시연용 비교 지표입니다.

## 검증

```sh
npm run test:smoke
npm run audit:assets
npm run build
npm run lint
```

분석 엔진·점수·공통 상태 변경이나 해결되지 않은 회귀 문제가 있으면 `npm run test:unit`과 `npm run test:e2e`로 범위를 넓힙니다. 현재 UI와 주요 흐름의 릴리스 확인은 Smoke와 변경 관련 테스트부터 진행합니다. 기본 테스트 서버는 5173 포트이며, 같은 주소의 서버가 실행 중이면 재사용합니다.

Production 검증 시에는 실제 배포 주소가 맞는지 확인한 뒤 지정합니다.

```powershell
$env:PLAYWRIGHT_BASE_URL = 'https://fitmate-team3.vercel.app'
npm run test:smoke
```

현재 저장 키는 `fitmate.cart.v1`, `fitmate.saved.v1`입니다. 저장된 점수 대신 현재 제품 구성으로 다시 계산합니다. 이전 `fitmate.intro.seen.v1` 키는 현재 사용하지 않으며, 인트로는 문서를 새로 불러올 때마다 표시됩니다. 브라우저 저장소를 사용할 수 없으면 새로고침 후 변경 내용이 유지되지 않을 수 있습니다.

QA·녹화·영상은 `artifacts/` 아래에 보관합니다. 발표 영상은 `artifacts/video/`, 빌드 결과는 `dist/`이며 `npm run build`로 재생성할 수 있습니다. `.vercel/`의 로컬 프로젝트 연결 정보와 배포 설정 `vercel.json`은 유지합니다.
