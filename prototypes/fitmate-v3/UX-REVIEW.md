# Fitmate V3 UI/UX 진단 · 구현 계획

기준: `docs/design-review/01-home-390x844.png`부터 `05-product-replacement-390x844.png`, PRD, 실제 소스 및 JSON. 대화에 첨부 이미지가 전달되지 않아 저장소의 대응 스크린샷을 사용했다. 임의의 인기·효능·임상 수치는 사용하지 않는다.

## 유지할 요소

화이트·쿨그레이·더스티 블루 #55789B, Pretendard, Fitmate 워드마크, 제품 컷아웃, 4개 하단 내비게이션, 조합 점수 원형 게이지, 비교와 근거 중심의 흐름을 유지한다. 전면적인 리브랜딩이 아니다.

1. 별도 폴더에서 원본 엔진 읽기 전용 번들, JSON 사본, 기존 이미지, 폰트 준비.
2. 홈과 탐색을 구현하고 390×844 렌더 확인.
3. 조합함, 삭제/추가, 점수 애니메이션, 저장·복원을 구현하고 검수.
4. 분석 상세, 실제 규칙 SVG, 출처, 질문, 교체 전후 비교를 구현하고 검수.
5. 320/390/430/1440 폭, 키보드/바텀시트/감소 모션/스크롤을 확인. 통합 가이드와 디자인 시스템 제공.

## 데이터 경계

17개 제품, 33개 주 규칙을 사용한다. 원본 두 번째 JSON의 12개 조건부 규칙은 기존 엔진과 동일하게 보류한다. 현재 모든 제품은 가상 DEMO이고 모든 성분 함량은 null이다. 점수는 기존 `demo-comparison-v1`만 사용한다. UI에 없는 시너지·과량 판정·안전 등급을 추가하지 않는다.

프로토타입은 AI API를 호출하지 않는다. 기존 React 앱에는 API 호출 코드가 있으나 배포 환경의 연결 여부를 이 프로토타입이 보증하지 않는다. 따라서 ‘규칙 기반 안내 · AI 생성 아님’ 상태만 실제로 동작시킨다.

## 화면별 구현 결과와 변경점

### 홈

브랜드 헤더와 기존 두 줄의 환영 문구를 유지했다. 제품 검색은 16px, 검색 바로 아래 실제 데이터가 있는 프로틴·비타민/미네랄·카페인·전체 바로가기를 배치했다. 추천은 메인 1개와 보조 행 1개로 위계를 나눴다. 제품 목록은 동일한 이미지 스테이지, 순번, 이름, 구성, 담기 버튼으로 정렬했다. ‘카탈로그 기본순 · 번호는 인기 순위가 아니에요’를 표시했다.

추천을 누르면 바로 현재 조합을 덮어쓰던 동작을 구성 미리보기 → 적용으로 바꿨다. 적용 후 8초 동안 되돌리기를 제공한다. 특정 성분 조합의 안전·효능을 추천하지 않는다.

### 조합함

회색 대형 카드와 그 안의 흰색 상세 버튼을 제거하고, 흰 화면 위에 176px SVG 링과 정보 요약을 나란히 두었다. 88 같은 숫자가 페이지의 첫 번째 핵심 정보다. 점수 아래 ‘의학적 안전도 아님’과 함량 누락 수를 표시한다. 주의 요약은 실제 매칭된 성분 이름을 보여줘 상세 화면의 내용을 예측할 수 있다.

제품 삭제는 명시적 X와 되돌리기를 제공한다. 수량 버튼은 용기 수량임을 설명한다. 하단 저장 CTA 80px와 내비게이션 72px를 구분하고 본문에는 추가 스크롤 여백을 확보했다. 따라서 첫 화면에 일부 제품이 아래로 이어지더라도 마지막 조작 버튼을 끝까지 스크롤해 가림 없이 사용할 수 있다.

담긴 제품 아래의 ‘상세 정보 확인’ 바로 다음에 ‘최적화 분석’ 버튼을 배치했다. 분석 상세를 거치지 않고 기존 제품 교체 비교 화면으로 진입한다. 후보가 없으면 기존의 비교 불가 안내를 보여준다.

### 분석 상세

두 번째 대형 게이지를 43px 점수 요약으로 바꿨다. 첫 화면에서 실제 원인, 규칙 ID, 감점, 성분 연결, 원문 설명, 미확인 조건을 볼 수 있다. 상세 버튼을 눌러야만 원인을 알 수 있던 구조를 해소했다. 고유 원인별 감점 명세, 중복 성분, 개선 비교, 질문, 분석 한계가 한 페이지에 이어진다.

성분 관계 SVG는 임의 네트워크가 아니라 현재 매칭된 `Finding`의 제품·성분 쌍이다. 칼슘과 레보티록신은 R06에 연결되고, 중복 예시는 R09에서 동일 성분 노드가 연결된다. 여러 원인은 칩으로 하나씩 선택한다. 등록 규칙 없는 유단백질 중복에는 연결선이나 감점을 만들지 않는다.

### 제품 탐색: 구체적인 통합 지침

- 상단 ‘보충제·영양제 / 복용약 확인’ 모드를 유지한다. 약은 일반 추천 목록과 분리한다.
- 모바일 상단의 큰 이미지 카테고리 띠를 44px 칩으로 대체한다. 가로 스크롤은 칩 영역에만 둔다. 홈 바로가기는 실제 항목이 있는 분류를 우선한다.
- 제품 이미지 스테이지 66×78px, 실제 컷아웃 47×64px를 기본으로 삼는다. 비율을 유지하며 확대 크롭하지 않는다. 배경은 동일한 쿨그레이로 통일한다.
- 같은 패키지를 사용하는 A/B/C는 해당 문자와 ‘유단백질 단일 / 칼슘 첨가 / 칼륨 첨가 구성’으로 구별한다. 패키지 그림만으로 제품 성분을 판단하지 않는다.
- 보조 설명을 15px로 올리고 제품명 17px, 담기 44px를 적용한다. 가격·후기·인기 배지를 만들지 않는다.
- 정렬은 기본순/이름순만 제공한다. 결과가 없으면 검색 초기화를 제공한다. 데이터가 없는 카테고리는 제품을 만들어 채우지 않는다.
- 담은 제품의 체크 버튼에는 ‘취소’를 표시하고 다시 누르면 담기를 취소한다. 탐색에서 같은 버튼을 눌러 수량을 늘리지 않는다. 용기 수량은 조합함에서만 조절한다. 취소 후에도 되돌리기가 가능하다.
- 탐색 상단 뒤로가기는 탐색을 연 홈/조합함 등 이전 화면과 스크롤 위치로 복귀한다. 제품 상세에는 현재 담김 상태에 따른 ‘담기 취소’와 독립적인 ‘닫고 돌아가기’를 제공한다.

### 최적화: 구체적인 통합 지침

- 제목을 ‘제품 교체 비교’로 구체화했다. 동일한 조합을 두 카드에 반복하던 구성을 전후 점수 1개 영역 + 변경되는 제품 2개로 줄였다.
- 원본 `getReplacementCandidates`의 결과만 선택기에 넣는다. 복용약, 공통 성분 없는 제품, 정보 누락 때문에 평가할 수 없는 제품을 후보로 만들지 않는다.
- 실제 비교 결과에 따라 점수 증가/감소/차이 없음을 모두 표현한다. ‘안전해졌어요’라는 문구나 성공을 암시하는 초록 점수는 사용하지 않는다.
- 사라진 원인과 새 원인을 나란히 설명하고 남은 함량 누락 수를 표시한다. 단지 제품 ID가 바뀌었다고 관계가 해소됐다고 쓰지 않는다.
- 후보 선택은 미리보기만 변경한다. ‘변경 조합 적용하기’에서 cart를 갱신하고, 원래 용기 수량과 약을 유지한 뒤 조합함에서 재계산한다. 토스트로 되돌릴 수 있다.
- 프로토타입은 비교 내용을 읽은 뒤 적용하도록 버튼을 본문 끝에 두었다. 실기기 분석에서 긴 페이지 이탈이 확인되면 하단 dock을 적용할 수 있으나, 내비게이션·safe area·본문 여백을 함께 맞춰야 한다.

### 저장 조합

기존 내 정보 내비게이션을 유지했다. 이름 입력 시트 → 로컬 저장 → 목록 → 현재 엔진으로 재계산해 복원까지 동작한다. 이 프로토타입에서 개인 체질 설정이나 인증을 새로 만들지 않았다. 저장 실패는 실패로 표시한다.

## 재사용 시스템

`tokens.css`를 공통 기준으로 사용한다. 실제 화면과 `design-system.html`은 같은 폰트·색상·버튼·게이지 스타일을 읽는다. 중요한 본문은 15–16px이며, 규칙 ID·데모 표기 등 메타데이터만 작게 사용한다. 일괄적인 둥근 카드 대신 제품 행, 구분선, 주의 배경, 주요 추천 영역을 구별한다.

| 인터랙션 | 실제 구현 | 감소 모션 |
|---|---|---|
| 제품 추가 | 체크 전환, 버튼/내비 배지 scale, live toast | 최종 체크·배지만 표시 |
| 게이지 | SVG pathLength 100 + 숫자, 동일 RAF 진행률 | 바로 최종 점수 |
| 관계 연결 | 현재 매칭 선만 650ms 1회 draw, 중앙 표식 강조 | 정적인 선과 표식 |
| 교체 비교 | 실제 전후 점수 보간, 새 제품 8px 이동 | 최종 비교값 즉시 |
| 바텀시트 | 네이티브 dialog, 30px 이동/opacity, 스크롤 잠금 | 즉시 열림 |
| 설명 | 선택 질문에 맞춘 규칙 텍스트, 300ms 등장 | 즉시 출력 |

일반 스크롤을 gesture handler로 가로채지 않는다. 전체 앱을 드래그 가능한 motion 컨테이너로 감싸지 않는다. 바텀시트는 native modal의 포커스 격리를 사용하고 닫힐 때 이전 스크롤·포커스를 복원한다. 같은 화면에서 제품을 추가할 때 전체 페이지 진입 모션을 재생하지 않는다.

## 출시 전 남은 범위

이 작업은 UX와 데이터 표현의 구현 검증이다. 실제 제품 사진·브랜드 구분 자산으로의 전환, 제품별 정확한 성분/함량 확보, 임상 규칙 검토, 실제 AI 배포 환경 확인은 별도 작업이다. 이번 결과에서 이런 항목이 완료됐다고 가정하지 않았다. 실기기 Safari/Android, 200% 글꼴 확대, VoiceOver/TalkBack, 스크린 키보드와 safe area 검수도 별도 출시 게이트로 남긴다.
