# 시연용 조합 비교 지표 정책

정책 버전: `demo-comparison-v1`.

두 JSON에는 정량 점수 산식이 없습니다. 이번 사용자 요청에 따라 정의한 **앱 시연 정책**이며, JSON의 임상 근거나 검증된 위험 수치가 아닙니다. 전문가 검증이 필요합니다. 100점도 의학적 안전·효능·흡수율을 보장하지 않습니다.

## 계산

- 기본값 100에서 등록 규칙의 고유한 성분 쌍별 점수를 차감합니다.
- `info`: 3점, `caution`: 12점, `high`: 25점. severity는 원본 그대로 사용하며 숫자는 임상 위험도가 아닌 비교용 가중치입니다.
- `max(0, 100 - 고유 원인별 감점 합계)`. 같은 원인은 정렬한 두 ingredient ID로 정의합니다.
- 한 원인이 여러 제품 쌍이나 여러 규칙에서 발견돼도 **가장 큰 감점 한 번**만 적용합니다. 근거에는 해당 규칙 ID와 제품 쌍을 모두 남깁니다.
- 규칙 표시의 중복 제거 키는 `[rule_id, 정렬한 product_id 두 개]`입니다. 표시 중복 제거와 감점 중복 제거는 구분합니다.
- 규칙 없는 성분 중복은 관찰 정보로만 표시하며 임의의 경고·감점을 추가하지 않습니다. 시너지 가점은 만들지 않습니다.
- 규칙의 `info` 감점은 확인할 정보가 있다는 시연 표시에 불과합니다. 중복 자체를 과다 섭취·독성으로 판정하지 않습니다.
- 비교 가능한 등록 성분 쌍이 없거나 해당 조합의 필수 규칙을 평가하지 못하면 숫자는 `null`이고 UI에는 `— / 분석 정보 부족`을 표시합니다.

## 데이터 부족

성분 목록 없음, 미등록 성분 ID, 함량/단위 누락, 지원하지 않는 필수 조건을 별도로 보고합니다. 이들을 0mg 또는 경고 없음으로 바꾸지 않습니다. 데이터 부족 자체에 임의의 감점을 주지 않습니다. 알려진 쌍만 계산한 지표는 부분적인 잠정 비교값입니다.

제품 수량은 용기 개수입니다. 수량 변경도 새 분석을 수행하지만 용기를 1일 섭취량으로 환산하지 않으므로 성분 관계가 같으면 점수도 같습니다. 실제 섭취량·시간이 없으므로 현재는 함량이 등록돼 있더라도 일일 합산·독성·과량 판정을 하지 않습니다.

## 조건 범위

- 주 데이터의 `different_cart_products_contain_each_ingredient` + `symmetric: true`를 양방향 비교합니다.
- 필수 조건으로 명시된 순수 `active_entities_present`, `distinct_products_same_ingredient`의 존재/서로 다른 제품 수 검사만 지원합니다. 모르는 연산자·추가 조건·방향·severity를 조용히 참으로 처리하지 않습니다.
- `original_condition_for_optional_detailed_evaluation`은 매칭 계약상 **선택 정밀 판정**입니다. 시간·제형·일일 섭취·변경 이력을 몰라도 성분 쌍 경고는 유지하고, 상세 판정은 미확인으로 남깁니다.
- `oral_drug_separation`의 시간 계산, `window: local_day`, `ingredient_scope`, `qualifier.any` 등의 추가 판정은 입력·검증 자료가 없어 수행하지 않습니다. 필수 조건이면 적용 보류, 선택 조건이면 기본 성분 쌍 경고와 한계를 함께 표시합니다.
- `supplement_interactions_with_lactose_ko.json`의 8개 `co_use_check`와 4개 `personal_condition_check`는 읽어 보류 이유와 원본 출처를 제공합니다. 개인 응답·고용량 조건·제품별 유당/제형을 확인할 수 없어 자동 경고나 감점으로 적용하지 않습니다.
- `potassium_supplement`을 `potassium`으로, 일반 `protein`을 WPC/WPI로, 약물 이름을 약물 계열 ID로 자동 치환하지 않습니다. 유당불내증을 병용금기나 우유 단백질 알레르기로 취급하지 않습니다.

## 교체 비교

현재 조합과 변경 조합은 같은 `analyzeCart` 함수를 사용합니다. 현재 목록의 보충제를 같은 JSON의 다른 보충제로 비교하되, 공통 등록 성분이 있고 성분 목록이 등록된 제품만 후보로 삼습니다. 이미 담긴 제품, 복용약, 성분 정보가 없는 제품은 후보에서 제외합니다.

다른 장바구니 제품의 성분이 누락되거나 미지원 필수 규칙이 있으면 후보 추천을 보류합니다. 평가하지 못한 관계를 없애서 개선된 것처럼 보이는 제안은 만들지 않습니다.

후보는 비교 지표와 새 주의 관계 수로 정렬하지만, 효능이 같거나 더 안전하다는 추천이 아닙니다. 데이터 부족과 개선 차이 없음은 명시합니다. 줄어든/새로운 관계는 고유 원인으로 비교하므로 제품 ID만 바뀌었다고 관계가 해소됐다고 표시하지 않습니다. 확정 시 용기 수량과 복용약을 유지하고, 변경 조합을 저장한 뒤 재계산된 결과 화면으로 이동합니다.

| 제품 | 규칙 | 비교 지표 |
| --- | --- | --- |
| P02 + M02 | R06, caution | 88 |
| P03 + M01 | R28, high | 75 |
| P04 + P05 | R01, info | 97 |
| P07 + M03 | R25, caution | 88 |
| P08 + P09 | R09, info | 97 |
| P01 + M01 | 매칭 없음 | 100 |

위 점수는 본 정책으로 계산한 시연 비교값이며 임상 평가가 아닙니다. 기존 고정 예시 82/88 전환은 제거합니다.
