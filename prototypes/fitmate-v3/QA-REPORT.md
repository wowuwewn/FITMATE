# Fitmate V3 프로토타입 검수

검수일: 2026-11-06 (Asia/Seoul). Chrome + Playwright, 로컬 HTTP와 `file://` 단일 HTML에서 확인했다.

## 확인한 동작

- 홈 검색, 빈 결과, 카테고리, 보충제 10개/복용약 7개 분리.
- 담기·삭제·되돌리기, 용기 수량 변경. 같은 제품 수량을 늘려도 감점이 증폭되지 않음.
- 탐색의 체크/‘취소’ 토글, 취소 후 되돌리기, 제품 상세의 담기 취소와 닫고 돌아가기. 탐색을 연 홈/조합함으로 돌아갈 때 이전 스크롤 위치 복원.
- 이름을 붙여 조합 저장, 내 정보 목록, 복원, 새로고침 후 유지.
- P02 + M02 = 88, P01로 교체 = 100(+12). 복용약 유지, R06 매칭 제거.
- P08 + P09 = 97, R09 및 비타민 D 중복 표시.
- P01 + P02: 유단백질 중복 관찰만 표시. 규칙이 없는 감점·관계선을 생성하지 않음.
- 여러 고유 원인의 SVG 선택과 설명 전환, 빈 조합/1개 제품의 숫자 `—` 처리.
- 원본 출처 URL 연결, 데이터셋 근거 수준과 시연 가중치의 구분.
- 질문에 따른 규칙 설명. AI API 요청 없음, ‘AI 생성 아님’ 표시.
- 바텀시트의 Tab 포커스 격리, Escape, 이전 포커스와 문서 스크롤 복원.
- 로컬 저장 JSON 손상 복구. 저장 공간 거부 시 시트 내부에 오류를 표시하며 성공으로 처리하지 않음.
- `prefers-reduced-motion`에서 점수·숫자·SVG·교체 비교의 최종 상태 즉시 표시.
- 홈에서 실제 터치 이벤트를 통한 가로 드래그 후 문서 가로 이동 없음.
- 분석 상세의 텍스트 크기를 200%로 확대한 시뮬레이션에서 문서 가로 넘침 없음.
- 디자인 시스템의 실제 엔진 게이지 88 ↔ 100 전환.
- 단일 HTML을 이미지/폰트 폴더가 없는 별도 경로로 옮긴 뒤 열어 홈, 교체, 저장 확인. 초기/핵심 동작 중 HTTP 요청 0건.

## 반응형 렌더

| 크기 | 확인한 화면 | 결과 |
|---|---|---|
| 320×568 | 홈·탐색·조합함·분석·교체·저장 | 가로 넘침 없음, 이미지·폰트 로딩 정상 |
| 390×844 | 동일 6개 화면 | 가로 넘침 없음, 주요 상호작용 검수 |
| 430×932 | 동일 6개 화면 | 가로 넘침 없음 |
| 1440×900 | 동일 6개 화면 | 모바일 앱 프레임 및 외부 설명 영역 정상 |

모든 크기에서 조합함 최하단 수량 버튼을 스크롤해 고정 CTA 위로 완전히 노출할 수 있음을 실제 좌표로 검사했다. 첫 화면에 모든 제품을 강제로 끼워 넣지 않으며, 세로 스크롤로 이어진다.

## 원본 보존

기존 `src`, `server`, `api`, 패키지 파일, PRD 및 점수 정책 등 51개 파일은 시작 시 기록한 SHA-256과 일치한다. 두 JSON 사본은 원본과 바이트 단위로 일치한다. 새 구현·문서·이미지 사본·QA는 `prototypes/fitmate-v3`에만 생성했다.

## 확인하지 않은 범위

실제 iPhone Safari·Android 기기, VoiceOver·TalkBack, 실제 브라우저/OS의 200% 글꼴 설정과 키보드 safe area는 별도 확인이 필요하다. 텍스트 확대 검수는 CSS를 이용한 시뮬레이션이며 OS 접근성 설정 검증을 대신하지 않는다. 출처 URL을 보존하고 연결 여부를 검사했으나 33개 규칙의 임상적 타당성·출처 최신성을 새로 검증한 것은 아니다. 생성형 AI API의 실제 운영 연결은 확인하지 않았다.
